# Trello Sync for Obsidian

Live bidirectional sync between Trello boards and your Obsidian notes.

## Installation

1. Install the plugin from Obsidian Community Plugins (or manually add it to `.obsidian/plugins/trellosync`).
2. Enable the plugin in settings.

## Usage

1. Open Plugin Settings and enter your **Trello API Key** and **API Token**.
2. Select the **Trello Board** you wish to sync.
3. Choose a target note or let the plugin create one for you.
4. Set the auto-sync interval (default: 30 seconds).
5. Click the sync icon on the ribbon or run `Sync Selected Trello Board` from the command palette.
